## Entry

> NOTICE: This machine is safe when operated exactly as instructed. You have already operated it incorrectly. Twice.

## How it works

`main.py` writes the chosen warning label to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. Run with `python3 main.py`.
